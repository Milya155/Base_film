# Base_film
## Этап 1
## 1.1	Определение цели и границ
Цель проекта: Подобрать фильм по индивидуальным критериям(актёры, жанр, оценка)

Целевая аудитория: Возрастные ограничения 16+

Основные сценарии: Пользователь задаёт вопрос на  естественном языке со своими предпочтениями и система выдаёт подборку подходящих фильмов

Ограничения: только текстовые рекомендации, без изображений

Состав команды:
## 1.2	Разработка онтологии
Сущности: 
- Фильм – название, продолжительность, год выпуска, описание
-	Рейтинг – оценка пользователя
-	Жанр – название жанра
-	Актёры – фио актёра


Связи: 
-	Фильм-Жанр (1:м)
-	Фильм-Актёр (м:м)
-	Актёр-Жанр(м:м)
-	Фильм-Рейтинг(м:м)
## 1.3	Сценарии использования
Примеры:
1.	Пользователь вводит жанр – система выдаёт фильм
2.	Пользователь устанавливает оценку – фильтрация
3.	Пользователь вводит актёра – система выдаёт фильм
4.	Пользователь вводит запрос на естественном языке – RAG-ответ
5.	Пользователь ищет похожие фильмы – семантический поиск
